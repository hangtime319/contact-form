# Formulário de Contato

Um formulário de contato responsivo com validação no lado do cliente, construído como um desafio do Frontend Mentor.

## Descrição

Este projeto é uma solução para o desafio "Formulário de contato". O objetivo principal foi criar um formulário de contato funcional e responsivo com validação integrada para guiar o usuário a fornecer as informações corretas. O foco foi em HTML para estruturar os campos do formulário, CSS para estilizar o formulário e suas mensagens de validação e, mais importante, **JavaScript** para lidar com a lógica de validação do formulário no lado do cliente, antes que uma "submissão" possa ocorrer.

## Tecnologias Usadas

* **HTML5:** Para criar a estrutura semântica do formulário e seus campos de entrada.
* **CSS3:** Para estilizar o formulário, implementar um layout responsivo e indicar visualmente os campos válidos ou inválidos.
* **JavaScript:** Usado para lidar com a lógica de validação do formulário. Ele verifica se os campos estão vazios, se os e-mails estão em um formato válido e fornece mensagens de erro em tempo real ao usuário.

## Instalação

Este é um site estático, então não é necessária uma configuração complexa. Para obter uma cópia local, basta seguir estes passos:

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/hangtime319/contact-form.git](https://github.com/hangtime319/contact-form.git)
    ```
2.  Abra o arquivo `index.html` no seu navegador da web preferido para visualizar o projeto.

## Uso

Este projeto demonstra um exemplo prático de um formulário de contato. Quando um usuário interage com o formulário, ele exibe:
* **Validação em tempo real:** Mensagens de erro aparecem à medida que o usuário preenche o formulário incorretamente.
* **Campos obrigatórios:** O formulário verifica se há campos vazios e solicita que o usuário os preencha.
* **Verificação de formato de e-mail:** Garante que o endereço de e-mail esteja em um formato válido.
* **Verificação de consentimento:** O formulário não pode ser enviado sem o consentimento do usuário.

## Funcionalidades

* **Validação no Lado do Cliente:** O formulário valida todas as entradas usando JavaScript antes de uma submissão teórica.
* **Mensagens de Erro Personalizadas:** Fornece feedback claro e fácil de entender quando um campo é inválido.
* **Design Responsivo:** O layout do formulário se adapta perfeitamente a diferentes tamanhos de tela.
* **UI Limpa e Moderna:** O design é simples e visualmente atraente, tornando o formulário fácil de usar.
