# Contact Form

A responsive contact form with client-side validation, built as a challenge from Frontend Mentor.

## Description

This project is a solution to the "Contact form" challenge. The main goal was to create a functional and responsive contact form with built-in validation to guide the user in providing the correct information. The focus was on HTML for structuring the form fields, CSS for styling the form and its validation messages, and, most importantly, **JavaScript** for handling the client-side form validation logic before a "submission" can occur.

## Technologies Used

* **HTML5:** For creating the semantic structure of the form and its input fields.
* **CSS3:** For styling the form, implementing a responsive layout, and visually indicating valid or invalid fields.
* **JavaScript:** Used to handle the form validation logic. It checks if fields are empty, if emails are in a valid format, and provides real-time error messages to the user.

## Usage

This project showcases a practical example of a contact form. When a user interacts with the form, it demonstrates:
* **Real-time validation:** Error messages appear as the user fills out the form incorrectly.
* **Required fields:** The form checks for empty fields and prompts the user to fill them out.
* **Email format check:** It ensures the email address is in a valid format.
* **Consent check:** The form cannot be submitted without the user's consent.

## Features

* **Client-side Validation:** The form validates all inputs using JavaScript before a theoretical submission.
* **Custom Error Messages:** Provides clear, user-friendly feedback when a field is invalid.
* **Responsive Design:** The form layout adapts seamlessly to different screen sizes.
* **Clean & Modern UI:** The design is simple and visually appealing, making the form easy to use.
